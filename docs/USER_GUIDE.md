# fnOSTV 电视端使用说明

适用于 Android 4.2 及以上的电视/电视盒子（重点适配 Android 4.4）。全程使用遥控器操作。

---

## 一、安装

1. 电视与电脑在同一局域网，电视开启 ADB 调试（部分电视叫「开发者选项 → USB/网络调试」）。
2. 电脑上执行：

```powershell
adb connect 电视IP:5555
adb install -r app-debug.apk
```

3. 电视应用列表里出现 **fnOSTV** 图标（蓝色方形 + 白色标记）即可打开。

> 也可以在电视上装一个文件管理器，把 APK 拷到 U 盘后直接安装。

## 二、首次登录

打开 App 直接进入登录卡片：

| 输入项 | 说明 |
| --- | --- |
| 服务器地址 | **只填 IP 或域名 + 端口**，例如 `10.0.0.40:5666`、`nas.example.com:5666`，不需要写 `http://` |
| 使用 HTTPS | 服务器开启 HTTPS 时勾选（会自动用 `https://`，WebSocket 走 `wss://`） |
| 信任证书异常 | 服务器是自签名/过期证书时勾选，否则会报证书错误 |
| 用户名 / 密码 | 飞牛（fnOS）账号，需要能访问影视的账号 |

选择「登录」后：
- 成功 → 直接进入首页
- 失败 → 卡片顶部显示失败原因，修改后重试即可

> 想换服务器或换账号：首页顶栏 → 用户图标 → **退出登录**，会回到登录卡片。
> 也可以进入设置页（顶栏齿轮）→ 播放偏好页的「切换账号」。

## 三、首页

从上到下依次是：

1. **媒体库**：服务端配置的影视库（电影、动画电影、电视剧…），卡片右下角显示条目数
2. **继续观看**：最近看到一半的内容
3. 各媒体库分区（每个库一行海报，最多 8 个 + 「查看全部」）

- 一行放不下时，按 **右方向键** 继续移动，整行会自动向左滚动
- 行尾的「› 查看全部」卡片可以直接进入该库的完整列表
- 首页内容全部来自服务器，登录成功后才会出现卡片

左侧栏：首页、收藏、媒体库列表、分类（全部 / 电影 / 电视节目 / 电视直播 / 其他）。
顶部右侧：搜索、用户菜单（只有“退出登录”）、设置。

## 四、遥控器按键

### 通用

| 按键 | 作用 |
| --- | --- |
| 方向键 | 移动焦点 |
| 确定 / OK | 打开、播放、确认 |
| 返回 | 逐层返回：播放器 → 详情 → 列表 → 首页 → 退出 |
| 菜单键 | 列表页：收藏 / 取消收藏 |

### 播放中

| 按键 | 作用 |
| --- | --- |
| 确定 / 播放暂停键 | 暂停 / 继续 |
| 左 / 右 | 快退 10 秒 / 快进 10 秒 |
| 快退 / 快进键 | 快退 30 秒 / 快进 30 秒 |
| 上 | 聚焦底部工具栏（播放类型 / 倍速 / 画面 / 清晰度），左右切换、确定执行 |
| 下 | 呼出横向选集面板（剧集）；无可选集时切换清晰度 |
| 菜单 | 切换倍速（1.0 / 1.25 / 1.5 / 2.0 / 0.75） |
| 长按确定 / 信息键 | 打开「播放信息」面板（解码方式、分辨率、片源、缓冲等） |
| 数字 1–9 | 跳到 10%–90% 位置 |
| 数字 0 | 回到开头 |

## 五、电视直播（IPTV）

1. 先在 **设置 → 播放偏好 → 电视直播源（IPTV）** 里填播单地址，例如：
   `https://cdn.jsdelivr.net/gh/iptv-org/iptv@master/streams/cn.m3u`
   或运营商抓包得到的 `xxx.txt`（`频道名,http://...` 一行一个），也支持 `file://` 本地文件。
2. 仓库里自带两份可直接用的播单：
   - `docs/iptv-guizhou-mobile.m3u`：贵州移动单播（161 个频道，需在贵州移动宽带下）
   - `docs/iptv-cn-public.m3u`：公共源实测可用（100 个频道，走普通宽带即可）
   把文件放到电视（或电脑共享）后，在设置里填对应路径/地址即可。
3. 回到侧栏点 **电视直播**：左边是频道分类（央视频道 / 卫视频道 / 电影频道 / 数字频道 /
   儿童频道 / 地方频道 / 综艺频道 / 纪录频道），右边是频道列表（带台标），背后直接播放直播画面。
4. 遥控器：上下选台、左右切换「分类 / 频道」两栏、确定播放、返回退出。
5. 频道播放失败很正常（公共源常常失效）：底部会弹一条小提示，菜单不会挡住，直接换个台；
   同一个频道掉线会自动重连（最多 4 次）。
6. 如果服务器媒体库里本身就有直播频道库，打开它也会自动进入这个直播菜单（不是海报网格）。

> 组播源（`udp://`、`rtp://`）需要电视和光猫在同一网段并已开通 IPTV；单播源（http/https m3u8）走宽带即可。
> HTTPS 源如果证书链不完整，VLC 会拒绝播放，优先选 http 源。

## 六、收藏

- 在文件/分类列表里按 **菜单键** 收藏或取消收藏；详情页也有收藏按钮
- 收藏保存在本机，并与服务端收藏**合并展示**（同一路径不会重复）
- 左侧栏「收藏」显示合并后的数量

## 七、设置

顶栏齿轮进入设置，共三页：

### 播放偏好
- **自动连播下一集**：剧集/同目录多个视频按顺序自动播放（电影不连播）
- **硬件解码优先**：Android 5.0 以上才生效；Android 4.4 的 VLC 侧固定软解以保证稳定
- **原画直连（电视硬解）**：4K / H.265 用电视芯片解码（画质最好、不占 CPU）。
  如果播放时电视黑屏或重启，把这个开关关掉，就会全部改走服务器转码（1080P，最稳）

### 外观
- **主题模式**：日升日落（可设日出/日落整点，白天浅色、夜间深色）、浅色、深色
- **卡片样式**：评分、分辨率、「已观看」✓ 标记 —— 开关后返回首页立即生效

### 关于
显示应用版本、服务器地址、当前账号。

## 八、常见问题

**Q：登录提示连接失败 / 超时？**
1. 确认电视能访问该 IP 和端口（先在同一网络用手机浏览器试 `http://IP:端口`）
2. 端口填对（飞牛默认 `5666`）
3. HTTPS 服务器记得勾选「使用 HTTPS」；自签名证书还要勾「信任证书异常」
4. 账号需要拥有影视访问权限

**Q：首页一直是空的？**
首页卡片全部来自服务端。若登录成功但为空，检查服务端是否已创建媒体库、账号是否有权限。

**Q：播放卡顿 / 花屏？**
Android 4.4 只能软解：
- 4K、HEVC(H.265)、10bit、高码率片源容易卡，属硬件性能限制
- 可在服务端把片源转码为 1080P H.264 后再播放（Web 端设置转码）
- 局域网建议用有线网络

**Q：播放时没有声音？**
App 已固定音频为立体声 PCM 输出，避免 4.4 直通失败。若仍无声，检查电视音量与服务器音轨是否为不支持的格式。

**Q：改了「已观看」开关但卡片没变化？**
新版本会立即刷新；如果没变化，确认片源已被服务端标记为已观看（未看完的不会显示 ✓）。

**Q：遥控器暂停/快进没反应？**
请在播放画面里按（先按任意键唤出控制条），部分电视的播放/暂停键会映射成媒体键，App 已同时支持。

**Q：怎么卸载/换设备？**
直接卸载 App。登录信息、收藏、最近播放都存在本机，卸载后清除。
